## Phase 2 — Pattern

This is toolchain drift between the policy-file-first quality gate and both project documentation and Session Config. Bare `python` is not a valid project runner in a uv-managed repository; its globally installed packages make failures host-dependent.

## Phase 3 — Impact

Affected:
- `.orchestrator/policy/quality-gates.json` test command.

Unaffected:

## Phase 4 — Solution

Change the policy test command from `cd backend && python -m pytest -q` to `cd backend && uv run pytest -q`, matching `AGENTS.md`, README, CI/container toolchain, and the lockfile. Then rerun the complete policy gate.
