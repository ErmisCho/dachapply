# TASK-209 Vite ownership probe quoting failure

## Symptom

The first PowerShell ownership probe failed with `Missing variable name after foreach` and showed its `$pids`, `$id`, and `$p` variables had disappeared.

## Root cause

The Bash wrapper received the PowerShell program inside double quotes, so Bash expanded PowerShell's `$...` variables before PowerShell parsed the script. This was a command-quoting defect, before any process lookup or termination.

## Resolution

The protected rerun identified only PID 250972, whose command line was the TASK-209 worktree's Vite binary with `--port 5175`. That exact process was stopped, and a follow-up listener check returned `task209_vite_stopped=true`.
