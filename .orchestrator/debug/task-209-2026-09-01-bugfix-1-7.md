# TASK-209 curl response-file path mismatch

## Symptom

A supplementary demo-login curl returned HTTP 200, then its Python body reader failed with `FileNotFoundError: '\\tmp\\task209-auth-body'`.

## Root cause

On this Windows Git-Bash setup, curl's `/tmp/...` output path and native Python's `Path('/tmp/...')` did not resolve to the same filesystem location. The HTTP request itself succeeded; only the unnecessary response-body read used incompatible path translation.

## Resolution

No retry is needed: browser DOM inspection independently proved the synthetic demo dashboard loaded and exposed the real TASK-209 control. Future mixed Bash/native-Python probes must use an explicit Windows path.
