# TASK-209 branch-dashboard auth probe redirect

## Symptom

The first branch-dashboard verifier exited 2 because `http://localhost:5175/` redirected to `/login`, so no Feedback deadlines button existed yet.

## Root cause

The isolated browser-tools profile had no valid local DACHApply session for this origin. Vite and the branch loaded correctly; `RequireAuth` performed its intended redirect. This is an authentication precondition, not a TASK-209 UI failure.

## Resolution

Synthetic demo login loaded the real branch Dashboard without owner credentials/data. Subsequent interaction measured the Feedback deadlines toggle, independent overdue behavior, and local-storage persistence.
