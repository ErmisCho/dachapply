# TASK-209 demo-login wait timeout

## Symptom

The corrected verifier clicked `Try demo` but timed out after 15 seconds waiting for `/` plus `Feedback deadlines`.

## Investigation

The click was confirmed before the wait began. The next step is to inspect the resulting URL, visible error text, browser console, and Vite proxy log before changing any code or retrying authentication.

## Root cause

The fixed 15-second combined login-and-panel wait was too tight for this remote-database demo dashboard load. Follow-up DOM inspection found the browser at `/`, with synthetic demo rows, `Feedback deadlines`, and the real `Hide upcoming` button; Vite had no error.

## Resolution

Treat authentication and panel readiness as separate observations and inspect the resulting DOM instead of assuming both settle within one fixed window. No product code changed for this verifier timeout.
