# TASK-209 backend ownership probe used reserved PowerShell variable

## Symptom

A supplementary port-8000 ownership probe reported `Cannot overwrite variable PID because it is read-only or constant` and then printed the probe PowerShell process itself.

## Root cause

PowerShell variable names are case-insensitive, so `$pid` collided with built-in `$PID` instead of becoming a local variable for the listening process. The fallback output therefore described the probe, not the server.

## Resolution

No retry is needed for TASK-209 behavior; API health was already HTTP 200 and this ownership probe was not used to stop anything. Future probes must use a non-reserved name such as `$ownerPid`.
