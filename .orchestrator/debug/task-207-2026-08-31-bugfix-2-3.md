# Debug session: TASK-207 MSYS converted taskkill switch
Created: 2026-08-31T13:56:00Z

## Phase 1 — Root Cause

### Error

```text
ERROR: Invalid argument/option - 'F:/'.
Type "TASKKILL /?" for usage.
exit code 1
```

### Reproduction

```bash
taskkill.exe /F /PID 236888
```

Environment: Git Bash/MSYS on Windows. Frequency: 1/1.

### Suspect commits

None; local verification command only.

### Instrumentation data

The error prints `F:/`, not `/F`, proving MSYS path conversion rewrote the Windows slash switch before `taskkill.exe` received it.

### Hypothesized root cause

MSYS treated `/F` as a path and converted it to `F:/`, so taskkill rejected the rewritten switch. · Confidence: high

## Phase 2 — Pattern

Native Windows CLI slash switches need doubled slashes or invocation through PowerShell/cmd when called from Git Bash.

## Phase 3 — Impact

No process was terminated and no product or data state changed.

## Phase 4 — Solution

Invoke `taskkill.exe //F //PID 236888`, then verify port 5173's new listener command line before browser testing.

## Resolution

Used doubled slash switches for the native Windows command; the verified released Vite PID was terminated without touching unrelated processes.
