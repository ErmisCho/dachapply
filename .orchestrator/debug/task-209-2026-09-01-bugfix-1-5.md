# TASK-209 demo-login verifier syntax error

## Symptom

The demo-login verifier failed to parse at `p.47351('button')` with `SyntaxError: Unexpected number`.

## Root cause

The one-line JavaScript was passed through Bash in double quotes. Puppeteer's `p.$$()` token was expanded by Bash, where `$$` means the current shell PID, producing `p.47351()` before Node saw it. No browser action ran.

## Resolution

The rerun located/clicked the demo button entirely inside `page.evaluate()`, avoiding shell-expanded Puppeteer selector tokens. The synthetic Dashboard loaded; no application code changed for this verifier error.
