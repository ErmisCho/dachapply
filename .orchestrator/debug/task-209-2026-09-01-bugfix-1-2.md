# TASK-209 browser verification process timeout

## Symptom

The direct Puppeteer verifier printed the complete expected TASK-209 result and saved its screenshot, but the shell wrapper reached its 120-second timeout.

## Evidence

The verifier found the exact branch harness URL, rendered the pause notice, counted zero `I sent this Gmail draft` buttons, and saved `task209-paused-followup.png`. `browser.disconnect()` did not make this one-shot Node process exit under the browser-tools connection.

## Root cause

This is verifier lifecycle residue, not application behavior: the output and screenshot completed before timeout, while Puppeteer's connection retained a live Node handle after disconnect. The next one-shot verifier must explicitly exit after disconnect; no application process or Chrome instance should be terminated.

## Resolution

An otherwise identical verifier called `process.exit(...)` only after assertions and `browser.disconnect()`. It exited normally in under 30 seconds with `pause=true`, `afterInterview=true`, and `sendButtons=0`. The application needed no change.
