### Suspect commits

- Current TASK-207 assertion counting the text `Reply to this message from`.
- Existing `MailboxReplyControl` icon contract writes the same label to both `aria-label` and `title`.

### Instrumentation data

The rendered thread has two non-draft messages and therefore two reply buttons. Each button contains the same phrase twice: once in `aria-label` and once in `title`. The broad text regex therefore returns four. The app-draft row contains neither attribute and correctly has no reply button.

### Hypothesized root cause

The assertion counted a label string that intentionally appears in two attributes per button instead of counting the unique `aria-label` attribute. · Confidence: high

## Phase 2 — Pattern

DOM-string tests must count an element/attribute boundary, not free text reused for accessibility and hover text.

## Phase 3 — Impact

Only the new test assertion is wrong; accessibility duplication and product UI should remain unchanged.

## Phase 4 — Solution

Count `aria-label="Reply to this message from` occurrences, which is exactly one per reply control.

## Resolution

Counted the unique `aria-label` attribute instead of duplicated free text; 17 focused frontend tests passed.
